# Makefile 结构分析与构建流程

## 项目概览

这是一个基于 **Buildroot v2021.05-rc2** 的嵌入式 Linux 构建系统（HiChipTech Linux SDK）。项目分为两层：

```
demo_baoze_issue/
└── hclinux/                        ← BR2_EXTERNAL 层（自定义包/配置）
    ├── Makefile                    ← 入口 Makefile（薄封装层）
    ├── external.mk                 ← 引入所有自定义 package .mk
    ├── external.desc               ← 标识: "HCLINUX"
    ├── configs/                    ← 70+ 个芯片/板级 defconfig
    ├── package/                    ← 自定义软件包 (hccast, ffmpeg, wifi驱动等)
    ├── board/                      ← 板级支持
    ├── boot/                       ← bootloader
    ├── linux/                      ← 内核
    ├── toolchain/                  ← 工具链
    └── buildroot/                  ← Buildroot 本体
        ├── Makefile                ← Buildroot 核心 Makefile（1260行）
        └── package/
            └── pkg-generic.mk      ← 每个包的通用构建规则
```

## 一、调用关系（从上到下）

### 1. 入口层 — `hclinux/Makefile`

```makefile
TOPDIR := $(CURDIR)
BUILDROOT_DIR := $(TOPDIR)/buildroot
MAKEARGS := -C $(BUILDROOT_DIR)
MAKEARGS += BR2_EXTERNAL=$(TOPDIR)   # 关键：将 hclinux 注册为外部扩展

_all:
    $(MAKE) $(MAKEARGS) $(FORWARD_GOALS)
```

**作用**：设置 `BR2_EXTERNAL` 指向 `hclinux/`，然后将所有 make 目标转发给 `buildroot/Makefile`。

### 2. 核心层 — `buildroot/Makefile`

```
all
 └── world                              (PHONY)
       └── target-post-image            (PHONY)
              ├── $(TARGETS_ROOTFS)     (如 ext4 / squashfs / cpio 等)
              │     └── target-finalize
              │           ├── $(PACKAGES)    ← 所有启用的包
              │           ├── strip 裁剪
              │           ├── rpath 修正
              │           ├── overlay 覆盖
              │           └── post-build scripts
              ├── staging-finalize
              └── post-image scripts    → 生成最终镜像文件
```

### 3. 包构建层 — `pkg-generic.mk`

每个包（如 `hccast`）的完整构建链：

```
<package> (即 hccast)
 └── <package>-install
       └── .stamp_target_installed
             └── <package>-build
                   └── .stamp_built
                         └── <package>-configure
                               └── .stamp_configured
                                     └── <package>-patch
                                           └── <package>-extract
                                                 └── <package>-source
```

对应到实际步骤：

```
source → extract → patch → configure → build → install
 下载      解压      打补丁     配置        编译      安装到 output/target/
```

每个步骤完成后会在 `output/build/<pkg>-<version>/` 下生成 `.stamp_*` 文件，make 通过检查这些 **stamp 文件** 判断步骤是否需要重新执行。

## 二、为什么改一个文件需要两步命令

Buildroot 将构建过程分为 **两个独立的阶段**：

### 阶段一：`make xxx-rebuild`

**做什么**：

```
xxx-clean-for-rebuild:
    删除 .stamp_built             ← build 的 stamp
    删除 .stamp_target_installed  ← install 的 stamp
         ↓
xxx (重新走完整个链):
    configure → build → 安装产物到 output/target/
```

**不做的事**：
- ❌ 不运行 `target-finalize`（strip 裁剪、rpath 修正、overlay 覆盖）
- ❌ 不运行 `target-post-image`（生成最终镜像）
- ❌ 不执行 post-build / post-image 脚本

### 阶段二：`make all`

`make all` = `make world` = `make target-post-image`，它会：

1. 检查所有包已是最新 → 因为 `xxx-rebuild` 刚装完，stamp 存在，包不会被重复构建
2. 运行 `target-finalize`：
   - 剔除调试信息 (strip)
   - 修正 RPATH
   - 复制 overlay 文件
   - 执行 post-build 脚本
3. 运行 `target-post-image`：
   - 执行 post-image 脚本
   - **生成最终烧录用的 rootfs 镜像文件**

### 一句话总结

```
make hccast-rebuild    →  把你的修改"编进"中间目录 output/target/
make all               →  把 output/target/ "打包成" 最终可烧录镜像
```

合并为一条命令：

```bash
make hccast-rebuild all
```

## 三、常用命令速查

### 按清理粒度分

| 命令 | 清除的 stamp | 用途 |
|---|---|---|
| `make xxx-reinstall` | install | 只改动了安装脚本/文件列表 |
| `make xxx-rebuild` | build + install | **最常用** — 只改了 `.c`/`.cpp` 文件 |
| `make xxx-reconfigure` | configure + build + install | 改了 Makefile.am / configure.ac |
| `make xxx-dirclean && make xxx` | 全部（含源码目录） | 彻底从头编译 |

### 其他有用的目标

| 命令 | 作用 |
|---|---|
| `make xxx` | 构建指定包及其依赖 |
| `make xxx-dirclean` | 删除包的 build 目录 |
| `make xxx-show-depends` | 查看包的依赖 |
| `make xxx-show-recursive-depends` | 查看包的递归依赖 |
| `make clean` | 清除所有构建产物（保留 .config） |
| `make distclean` | 清除所有产物 + .config |
| `make menuconfig` | 图形化配置界面 |
| `make V=1` | 显示完整编译命令（默认静默） |

## 四、关键文件索引

| 文件 | 作用 |
|---|---|
| `hclinux/Makefile` | 入口，设置 BR2_EXTERNAL，转发到 buildroot |
| `hclinux/external.mk` | 引入所有自定义 package .mk 文件 |
| `hclinux/external.desc` | BR2_EXTERNAL 标识（名称: HCLINUX） |
| `hclinux/buildroot/Makefile` | Buildroot 核心 Makefile，定义 all/world/clean 等顶层目标 |
| `hclinux/buildroot/package/pkg-generic.mk` | 通用包构建规则定义（source/extract/patch/configure/build/install 链及 -rebuild 等快捷目标） |
| `hclinux/configs/*_defconfig` | 各芯片/板级的默认配置文件 |
| `hclinux/package/*/*.mk` | 各自定义包的构建规则 |
