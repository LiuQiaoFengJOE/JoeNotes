# 🔬 海奇 HC16xx/HC17xx 嵌入式 Linux SDK 深度解析

## 项目概览

这是一个**真实工业级嵌入式 Linux SDK**，来自海奇半导体 (HiChip Semiconductor)，基于 **Buildroot v2021.05-rc2**，面向 **MIPS 74Kc** 处理器，用于投影仪、无线同屏器、HDMI 显示等音视频产品。

```
demo_baoze_issue/
├── hclinux/                          ← BR2_EXTERNAL 层 (整个SDK)
│   ├── Makefile                      ← 入口 Makefile
│   ├── Config.in                     ← 顶层 Kconfig (芯片选型、启动方式)
│   ├── external.mk / external.desc   ← Buildroot 外部扩展注册
│   ├── configs/                      ← 70+ 个板级 defconfig
│   ├── boot/hcboot/                  ← 自研 Bootloader (hcboot)
│   ├── board/hichip/                 ← 板级支持 (DTS、内核配置、DDR初始化)
│   ├── linux/                        ← 内核补丁 + 自研驱动
│   │   └── linux-drivers/            ← 海奇芯片全部内核驱动源码
│   ├── package/                      ← 50+ 用户态软件包 (WiFi驱动、投屏、GUI等)
│   ├── buildroot/                    ← Buildroot 构建系统本体
│   ├── toolchain/                    ← MIPS 交叉编译工具链
│   ├── patches/                      ← 各组件补丁
│   └── document/                     ← 20+ 份开发文档
└── 1.F7100-HDMI出来没有60帧/          ← 典型客户 issue: HDMI 帧率调试
```

## 一、Bootloader 的移植与裁切

### 1.1 本项目使用自研 Bootloader: **hcboot**

与通用 U-Boot 不同，海奇选择自研 hcboot，因为：
- **代码量极小**（适合 SPI NOR Flash 的 ~512KB 启动分区）
- **启动速度极快**（投影仪/同屏器要求秒级开机）
- **深度定制**（与 AVP 协处理器配合、支持双核启动）

### 1.2 关键配置文件

| 文件 | 作用 |
|------|------|
| `boot/hcboot/Config.in` | 声明 "HC-Boot" 选项，与 U-Boot 互斥 |
| `boot/hcboot/hcboot.mk` | 构建规则：读取 defconfig → 编译 DTB → 生成镜像 |
| `board/.../hcboot-configs/*_defconfig` | 各板级的 bootloader 配置 |

### 1.3 hcboot 的核心能力（从 defconfig 可读出）

从 `hichip_hc16xx_linux_bl_defconfig`:
```kconfig
CONFIG_BOOT_SELFCOMPRESSED=y       # 自解压（LZMA压缩固件）
CONFIG_BOOT_KEYSTONE=y             # 密钥校验（安全启动）
CONFIG_BOOT_SHOWLOGO=y             # 启动时显示 Logo
CONFIG_BOOT_HCLINUX_DUALCORE=y     # 双核启动（Linux + AVP协处理器）
CONFIG_BOOT_UPGRADE=y              # 支持 USB/SD/网络 升级
CONFIG_BOOT_BACKLIGHT=y            # 背光控制
CONFIG_BOOT_LCD=y                  # LCD 初始化
```

**裁切关键点**：通过 Kconfig 精细控制每个功能模块，不需要的功能直接不编译。例如 SPI NAND 启动 vs SPI NOR 启动，通过 `BR2_EXTERNAL_BOOT_TYPE_*` 选择。

### 1.4 启动介质支持

```kconfig
# Config.in 中的启动方式选择
BR2_EXTERNAL_BOOT_TYPE_SPINOR      # SPI NOR Flash
BR2_EXTERNAL_BOOT_TYPE_SPINAND     # SPI NAND Flash
BR2_EXTERNAL_BOOT_TYPE_SDMMC       # SD/MMC 卡启动
```

每种启动介质的参数（page size、erase size）都可以精细配置。

### 2.1 内核多版本支持

### 2.2 设备树 (Device Tree) 架构

这是本项目的**核心学习价值**所在 — 完整的工业级 DTS 层级结构：

```

├── CPU 节点 (MIPS 74Kc, 时钟配置)
├── 中断控制器 (intc, cpuintc)
├── 时钟树 (PLL, CPU clk, MMC clk)
├── 4× UART (ns16550a 兼容)
├── 4× 自研 UART (hichip,hc_uart)
├── 4× I2C
├── SPI Flash / SPI Master
├── NAND Flash Controller
├── 2× USB (MUSB, host/peripheral)
├── SD/MMC (Synopsys DW MSHC)
├── 以太网 (TOE - TCP Offload Engine)
├── IR 遥控器接收器
├── ADC 按键 (6通道)
├── PWM
├── Watchdog
├── FrameBuffer (2个图层)
├── 2D Graphics Engine (GE)
├── LVDS / MIPI / DSC
├── Audio (I2S, SPDIF, PCM)
├── PinCtrl (128 pin 管理)
├── 4× GPIO Bank (L/B/R/T, 各32pin)
└── AVP-Proxy 设备 (音视频协处理器通信)

hc16xx-db-d3100-v20.dts               ← 板级 DTS (客户板卡)
├── 引用 common.dtsi
├── 定义内存布局
├── 配置 bootargs
├── 使能/禁用各外设 (status = "okay"/"disabled")
├── 配置 Framebuffer (分辨率、图层)
├── 配置 PinCtrl 功能映射
├── Flash 分区表
└── 引入 LCD 面板参数 (lcd_lvds_1024_600_vesa.dtsi)
```

### 2.3 设备树编写关键知识点

**Flash 分区表** (在板级 DTS 中定义):
```dts
&spi_flash {
    partitions {
        nor@0        { label = "nor";   reg = <0x0      0x1000000>; };
        boot@0       { label = "boot";  reg = <0x0      0x80000>;   };  // 512KB
        dtb@80000    { label = "dtb";   reg = <0x80000  0x10000>;   };  // 64KB
        avp@90000    { label = "avp";   reg = <0x90000  0x1a0000>;  };  // AVP固件
        linux@230000 { label = "linux"; reg = <0x230000 0x300000>;  };  // 内核
        rootfs@530000{ label = "rootfs";reg = <0x530000 0xa80000>;  };  // 根文件系统
        eromfs@fb0000{ label = "eromfs";reg = <0xfb0000 0x30000>;  };
        persistentmem@fe0000 { label = "persistentmem"; ... };        // 持久化存储
    };
};
```

**PinCtrl 配置** (引脚功能复用):
```dts
&pinctrl {
    functions {
        pctl_uart1: pctl_uart1 {
            groups = "GPIO_T_14", "GPIO_T_19";  // UART1 使用这2个引脚
            field-value-0 = <0x2>;               // 功能码=2: UART模式
            field-value-1 = <0x2>;
        };
    };
};
&hc_uart1 {
    pinctrl-0 = <&pctl_uart1>;   // 引用上面的 pinmux 配置
    status = "okay";
};
```

**内存划分** (双核系统):
```dts
/* 总内存减去 AVP 协处理器占用，剩余给 Linux */
#define CONFIG_LINUX_MEMORY_SIZE (CONFIG_MEMORY_SIZE - AVP_SYSMEM - AVP_MMZ)
```

## 三、内核架构 (MIPS 平台移植)

### 3.1 平台代码结构

```
linux/linux-drivers/arch/mips/hc16xx/
├── Platform          ← 编译参数 (arch/mips/Kbuild 引用)
├── Makefile          ← 目标文件列表
├── init.c            ← CPU 时钟初始化 (PLL 配置，从 DTS 读取)
├── board.c           ← 板级初始化 (重启、关机、寄存器读写)
├── irq.c             ← 中断控制器驱动 (级联 MIPS CPU IRQ → 96路外设IRQ)
├── cmdline.c         ← 命令行参数处理
├── prom.c / prom.h   ← PROM 接口 (早期启动)
├── serial.c          ← 早期串口 (earlycon)
└── time.c            ← 时间相关
```

### 3.2 中断控制器 (核心平台代码)

从 `irq.c` 可以看到经典的中断级联架构：

```
MIPS CPU (CAUSEF_IP2~IP7)
  └── hichip,generic-intc (96路外设中断)
       ├── IRQ 0-31  → status_regs[0], enable_regs[0]
       ├── IRQ 32-63 → status_regs[1], enable_regs[1]
       └── IRQ 64-95 → mailbox 中断 (多核通信)
```

关键代码流程：
- `arch_init_irq()` → 注册 `intc_of_init` 回调
- `intc_of_init()` → 从 DTS 读取寄存器、创建 irq_domain、注册级联 handler
- `plat_irq_dispatch()` → CPU 中断分发入口（汇编调用）

### 3.3 CPU 时钟配置

`init.c` 的 `hc16xx_set_cpu_clk()` 直接在寄存器层面操作 PLL：
- 从 DTS `/cpus/cpu@0` 节点读取 `clock` 和 `mcpu-dig-pll-clk`
- 支持 8 档频率：594/396/297/198/900/1188/24MHz + 数字PLL可调
- HC17xx 还支持 ADPLL（全数字锁相环）实现更高精度调频

### 4.2 GPIO 驱动深度分析

`gpio-hc.c` 是一个**教科书级的 platform_driver**：

```c
// 1. 匹配 DTS 中的 compatible 字符串
static const struct of_device_id hc_gpio_of_match[] = {
    { .compatible = "hichip,hc-gpio" },
    {}
};

// 2. probe 函数：从 DTS 读取配置，初始化硬件
static int hc_gpio_probe(struct platform_device *pdev) {
    // 读取 DTS 属性 ngpio, gpio-base
    // ioremap 寄存器
    // 填充 gpio_chip 结构体 (direction, get, set, request, free, to_irq)
    // 注册 GPIO 中断控制器
    gpiochip_add_data(&hc_gpio->chip, hc_gpio);
}

// 3. 通过 arch_initcall 确保在大多数设备之前初始化
arch_initcall(hc_gpio_init);
```

**关键设计模式**：
- **分层结构**：`hc_gpio` → `gpio_chip` → `irq_domain` → `irq_chip_generic`
- **中断支持**：GPIO 可做 IRQ 源，支持上升沿/下降沿
- **PinCtrl 集成**：GPIO 申请时自动调用 `pinctrl_gpio_request()` 切换引脚功能

### 4.3 PinCtrl 驱动（核心基础设施）

`pinctrl-hc16xx.c` 是最复杂的驱动，管理 128 个引脚的复用：

```
DTS 配置
  ├── pins: 128 个引脚名称 (GPIO_L_00 ~ GPIO_T_31)
  ├── groups: 每个引脚对应的寄存器偏移
  │   └── GPIO_L_00 { pins = <0>; reg-offset = <0x4a0>; }
  ├── gpio-groups: 引脚按 Bank 分组 (L/B/R/T)
  │   └── GPIO_L@gpio-group1 { pins = <0..31>; reg = <0x188004a0 0x30>; }
  └── functions: pinmux 功能定义
      └── pctl_uart1 { groups = "GPIO_T_14","GPIO_T_19"; field-value-0 = <0x2>; }
```

### 4.4 Watchdog 驱动

`hc_watchdog.c` 展示了 **Linux watchdog 框架**的标准用法：

```c
static struct watchdog_ops hc_wdt_ops = {
    .start       = hc_wdt_start,     // 启动看门狗
    .stop        = hc_wdt_stop,      // 停止看门狗
    .ping        = hc_wdt_ping,      // 喂狗
    .set_timeout = hc_wdt_set_timeout, // 设置超时
    .get_timeleft = hc_wdt_get_timeleft, // 查询剩余时间
};
```

**高级功能**：
- **AVP 协处理器存活检测** (`CONFIG_WDT_FEED_RELAY_AVP`)：喂狗前先检查 AVP 是否正常
- **自动喂狗线程** (`CONFIG_WDT_AUTO_FEED`)：内核线程定期喂狗
- **定时器模式** (`CONFIG_WDT_MODE_TIMER`)：可作为普通定时器使用，触发 notifier 回调链

### 4.5 Clocksource Timer 驱动

`timer-hc16xx.c` 展示了 **clockevent + clocksource + sched_clock** 三位一体的实现：

```c
// 1. Clockevent: 提供 timer tick (周期性/oneshot)
static struct clock_event_device hc16xx_clockevent = {
    .features = CLOCK_EVT_FEAT_PERIODIC | CLOCK_EVT_FEAT_ONESHOT,
    .set_next_event = hc16xx_clkevt_next_event,
};

// 2. Clocksource: 提供高精度时间戳
clocksource_mmio_init(timer_base + SB_TIMER_CNT_REG, ...);

// 3. Sched clock: 调度器使用的时间源
sched_clock_register(hc16xx_timer_sched_read, 32, timer_rate);

// 通过 TIMER_OF_DECLARE 宏在早期启动阶段自动初始化
TIMER_OF_DECLARE(sb_timer, "hichip,south-bridge-timer", hc16xx_timer_init);
```

## 五、启动流程

### 5.1 完整启动链

```
┌─────────────────────────────────────────────────────────────┐
│  硬件上电                                                     │
│    ↓                                                        │
│  ROM Boot (芯片内置)                                          │
│    ↓ 读取 Flash 起始位置                                      │
│  hcboot (第一级Bootloader)                                    │
│    ├── 初始化 DDR (ddrinit .abs 文件)                        │
│    ├── 初始化时钟/PLL (Set CPU clock)                         │
│    ├── 初始化 SPI Flash / NAND                                │
│    ├── 配置 PinMux (从 DTS)                                   │
│    ├── 显示 Logo (如果需要)                                   │
│    ├── 检查升级条件 (USB/SD/网络)                             │
│    ├── 加载 Linux 内核镜像 → 解压 (LZMA/GZIP)                 │
│    ├── 加载 DTB 到内存                                        │
│    ├── 加载 AVP 固件 (双核模式)                               │
│    └── 跳转到内核入口                                         │
├─────────────────────────────────────────────────────────────┤
│  Linux Kernel (arch/mips/boot/)                               │
│    ├── kernel_entry (汇编入口)                                │
│    ├── plat_mem_setup()    — 内存初始化                       │
│    ├── prom_soc_init()     — board.c，在 board.c 中           │
│    │   ├── 扫描 DTS 中的 platform-setup-setbit (引脚初始化)   │
│    │   ├── 设置 _machine_restart / _machine_halt              │
│    │   └── hc16xx_set_cpu_clk() — 设定 CPU 频率              │
│    ├── arch_init_irq()     — irq.c，注册中断控制器            │
│    ├── 时钟源初始化 (TIMER_OF_DECLARE)                        │
│    ├── start_kernel()                                         │
│    │   ├── setup_arch()                                       │
│    │   ├── init_IRQ()                                         │
│    │   ├── time_init()                                        │
│    │   ├── rest_init() → kernel_init()                        │
│    │   │   └── do_initcalls()                                 │
│    │   │       ├── postcore_initcall → pinctrl                │
│    │   │       ├── arch_initcall → gpio                       │
│    │   │       ├── subsys_initcall → i2c, spi, ...            │
│    │   │       ├── device_initcall → fb, eth, sound, ...      │
│    │   │       └── module_init → watchdog, wifi, ...          │
│    │   └── 挂载 rootfs → 执行 /linuxrc (init)                 │
│    └── 用户空间启动                                           │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 关键启动流程文件索引

| 文件 | 启动阶段 | 作用 |
|------|---------|------|
| `boot/hcboot/` | Bootloader | 硬件初始化、加载内核 |
| `arch/mips/hc16xx/board.c` | 早期内核 | CPU频率、平台setup、重启 |

## 六、学习路径建议

基于本项目，按以下顺序学习最有效：

### 第一周：构建系统与配置
1. **阅读** `Makefile结构分析.md`（你已经有了）
2. **对比** 两三个不同的 `configs/*_defconfig`，理解配置差异
3. **学习** `Config.in` 的菜单层次 — 这是 Kconfig 的实战教材

### 第二周：Bootloader
1. **研究** `hcboot/` 的构建流程 (hcboot.mk)
2. **对比** hcboot 的 `_defconfig` 与 Linux 的 defconfig
3. **理解** DDR 初始化文件 (`.abs` 二进制 + GDB 脚本)

### 第三周：设备树
1. **精读** `hc16xx-common.dtsi` — 这是SoC级DTS的标准范本
2. **对比** 多个板级 `.dts`，理解硬件差异如何通过DTS表达
3. **练习**：对照芯片手册，修改某个外设的DTS配置

### 第四周：内核驱动
1. **GPIO驱动** (`gpio-hc.c`) — 最简洁，第一个读
2. **Watchdog驱动** (`hc_watchdog.c`) — 理解 watchdog 框架
3. **PinCtrl驱动** (`pinctrl-hc16xx.c`) — 理解 pinmux 子系统
4. **中断控制器** (`irq.c`) — 理解 MIPS 中断级联

### 第五周：启动流程与调试
1. **追踪** 从 hcboot 到 kernel_init 的完整链路
2. **研究** `1.F7100-HDMI出来没有60帧/` 这个真实 issue 的调试过程
3. **阅读** `document/` 下的开发文档（GPIO、UART、PWM使用说明）
