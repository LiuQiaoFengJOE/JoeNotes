## Dedupe Rule

- Search the target file before adding a question.
- If the same meaning already exists, do not add a near-duplicate.
- If the same topic exists but the angle is new, rewrite the wording to fit the existing style and keep it short.
- Treat missing concrete detail as a new angle. Examples include wire count, lane count, pin count, timing sequence, register impact, boundary condition, and troubleshooting path.
- Prefer adding the new angle under the existing topic section instead of skipping it.
