*2025.10 – 2026.03 | 今日芯科技*

基于**亿智 SV826** 平台开发的 Linux 4K 运动相机，搭载 Linux 4.19 内核，支持真 4K@30fps 高清录像、电子防抖（EIS）、WiFi 图传、手机 APP 远程控制。

**个人负责模块：**
- **Linux 系统移植与优化：** 搭建交叉编译环境（arm-linux-gcc 8.3），完成 Uboot 适配、Linux 内核配置裁剪（精简 USB/PCIe 等无关驱动）、Buildroot 根文件系统制作与开机自启动脚本优化，系统冷启动时间控制在 5 秒以内。
- **Camera Sensor 驱动适配：** 基于亿智 BSP 框架完成 Sony IMX386 MIPI Sensor 驱动移植，配置 sensor 上电时序、初始化寄存器序列、MIPI  lane 配置，适配亿智 VI 视频输入通路，调试并解决 sensor 在高温环境下 I2C 通信异常导致的花屏问题。
- **视频采集与编码：** 配置亿智视频编码管线（VI → ISP → VENC → MUX），实现 4K@30fps / 2K@60fps / 1080P@120fps 多分辨率动态切换；利用平台硬编码器实现 H.264/H.265 双编码格式支持；适配 MP4/TS/MOV 三种封装格式及循环录像机制。
- **音频模块：** 集成 I2S 数字硅麦，完成音频 PCM 采集、AAC 编码及音视频同步封装。
- **WiFi 图传与 APP 联调：** 基于 Realtek RTL8189 WiFi 模组实现 STA/AP 双模式切换，配合 APP 端完成低延迟视频图传（720P 预览）及远程控制指令（录像启停、拍照、参数设置）。
- **EIS 电子防抖：** 对接 Gyro（陀螺仪）SPI 数据采集，配合亿智 ISP 模块实现电子防抖功能，解决运动场景下的视频抖动问题。
- **功耗与电源管理：** 实现电池电量分段采样 + 放电曲线校准、低电量自动关机保护、关机电容续电完成文件收尾写入。
