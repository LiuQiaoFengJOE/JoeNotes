### 一、IPC 网络摄像头（Linux）| iCatch V57A 平台
*2024.10 – 2025.06 | 烽航实业*

基于 iCatch V57A + Linux 开发的家用 IPC 网络摄像头，支持高清视频采集、RTSP 局域网推流、APP 在线预览与回放。

**个人负责模块：**
- Linux 系统环境搭建：交叉编译工具链配置、内核裁剪（剔除 USB HID/声卡等无关驱动）、文件系统精简、开机自启动脚本优化，最终系统冷启动时间控制在 6 秒以内。
- Sensor 驱动适配：根据 datasheet 配置 sensor 初始化寄存器序列，适配 iCatch VI 通路，调整输入分辨率与帧率。解决过 sensor 上电时序异常导致偶发性识别失败的问题。
- 网络传输：基于 live555 库实现 RTSP server 端推流，调试局域网 WiFi 环境下的码流传输延迟（局域网延迟控制在 200ms 以内），解决 WiFi 弱信号下码流卡顿的问题。
- 配网功能：实现 WiFi STA 模式下的 SoftAP 配网流程 + 一键复位配网，配合 APP 端完成配网联调。
